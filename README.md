## Calculator App in C#

A simple console-based calculator application developed in C# using .NET.
This project performs basic and advanced mathematical operations through an interactive menu system.

## 🚀 Features

- Addition
- Substraction
- Multiplication
- Division
- Modulus
- Exponentiation
- Square Root
- Loop system for multiple calculations
- Error handling for division by zero
- User-friendly console interface

## 🛠️ Technologies Used
- C#
- Console Application
- Git & Github
